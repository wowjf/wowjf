## Engineering Principles

> **Determinism over vibes.** LLMs are probabilistic; production systems can't afford to be. I build constraint systems that make AI output verifiable.

> **Security is not a feature flag.** OWASP enforcement, JWT purpose-binding, atomic writes — designed in from commit one, not patched in after an incident.

> **Ship for the LTS horizon.** Version-locked dependency matrices, expand/contract migrations, and compliance gates that refuse to let work finish half-done.
